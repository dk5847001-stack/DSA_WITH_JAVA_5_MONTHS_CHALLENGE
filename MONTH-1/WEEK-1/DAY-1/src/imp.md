# Java Environment & First Program — Important Notes

> Month 1 · Week 1 · Day 1 | Quick revision sheet

## Must Remember
- JDK = development tools; JRE = runtime libraries + JVM; JVM executes bytecode.
- Flow: `.java` source → `javac` → `.class` bytecode → JVM.
- `public static void main(String[] args)` is the standard entry point; filename must match a public class.
- Compile/run from the correct package root; package declaration must match folder structure.

## Quick Complexity / Rules
- Count each loop iteration and nested loop separately.
- Time complexity describes growth with input size; auxiliary space counts extra memory.
- Test empty/minimum, typical, boundary, and invalid inputs.

## Common Traps
- Off-by-one conditions, integer overflow, wrong operator precedence, and unhandled edge cases.
- Do not memorize code blindly: explain why each condition and update is required.
