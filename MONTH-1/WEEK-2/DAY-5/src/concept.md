# Factorial, Fibonacci, GCD & LCM — Concept Notes

> **Roadmap:** Month 1 · Week 2 · Day 5

## Core Idea
Use integer arithmetic deliberately: % extracts remainder, / removes last digit, sqrt-bound factor checks reduce work, and GCD uses Euclid's remainder recurrence.

## Important Concepts
- Understand the definition, purpose, and situations in which this technique/data structure is useful.
- Identify the input constraints and the invariant or state that must remain true during execution.
- Compare a straightforward solution with an optimized one; explain why the optimized approach is correct.
- For Java, use clear method boundaries, meaningful names, safe types, and standard library APIs where appropriate.

## Implementation & Dry Run
1. Write a tiny example and predict the expected output before coding.
2. Trace variable/reference/state changes after every important operation.
3. Test empty/minimum input, one element, duplicates, boundary values, and maximum constraints.
4. Re-implement from a blank file without copying a previous solution.

## Complexity Notes
- **Time:** Count iterations, recursive calls, sorting, and data-structure operations.
- **Auxiliary space:** Count extra arrays, collections, recursion stack, and temporary storage.
- State best/average/worst case when input arrangement changes the work; justify every Big-O claim.

## Common Mistakes
- Off-by-one indices, incorrect base/termination conditions, stale state, null handling, and integer overflow.
- Choosing an algorithm without checking its preconditions.
- Reporting complexity without accounting for nested operations or extra memory.
