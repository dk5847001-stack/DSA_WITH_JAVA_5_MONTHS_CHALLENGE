# OOP Basics: Class, Object & Encapsulation — Important Notes

> Month 1 · Week 4 · Day 3 | Quick revision sheet

## Must Remember
- Class defines state/behavior; object is an instance. Constructor initializes object state.
- Encapsulation: keep fields private and expose controlled methods/accessors.
- `this` refers to the current object; use constructor chaining with `this(...)`.
- Prefer invariants: prevent invalid object state at construction/update.

## Complexity / Correctness
- Identify dominant operations and count auxiliary storage separately from input.
- State preconditions and explain why the chosen operation/algorithm is valid.
- Prefer the simplest data structure that matches required operations.

## Common Traps
- Reference-vs-value confusion, mutation assumptions, index boundaries, and integer overflow.
- Test empty/minimum, typical, boundary, and invalid inputs.
