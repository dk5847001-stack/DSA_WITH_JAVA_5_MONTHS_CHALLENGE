# OOP Advanced: Inheritance & Polymorphism — Important Notes

> Month 1 · Week 4 · Day 4 | Quick revision sheet

## Must Remember
- Inheritance models an is-a relationship; `extends` reuses/overrides behavior.
- Overriding requires compatible signature; `@Override` catches mistakes; runtime polymorphism dispatches by actual object type.
- `super` accesses parent constructor/method; Java classes have single class inheritance.
- Favor composition when inheritance does not represent a true is-a relationship.

## Complexity / Correctness
- Identify dominant operations and count auxiliary storage separately from input.
- State preconditions and explain why the chosen operation/algorithm is valid.
- Prefer the simplest data structure that matches required operations.

## Common Traps
- Reference-vs-value confusion, mutation assumptions, index boundaries, and integer overflow.
- Test empty/minimum, typical, boundary, and invalid inputs.
