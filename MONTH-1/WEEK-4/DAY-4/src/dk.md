## Knowledge Snapshot
- Inheritance models an is-a relationship; `extends` reuses/overrides behavior.
- Overriding requires compatible signature; `@Override` catches mistakes; runtime polymorphism dispatches by actual object type.
- `super` accesses parent constructor/method; Java classes have single class inheritance.
