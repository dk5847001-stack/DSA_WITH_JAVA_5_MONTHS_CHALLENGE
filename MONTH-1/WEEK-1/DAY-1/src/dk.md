# Java environment and first program — Daily Knowledge

> MONTH-1 · WEEK-1 · DAY-1 | Daily learning journal

## 1. Core Knowledge
- Java environment and first program is the focus of this study session; understand its purpose, inputs, outputs, and the conditions under which it is useful.
- Identify the core data/state being maintained and the exact operation performed at each step.
- In Java, choose suitable types and standard library tools; keep boundary conditions explicit.

## 2. Mental Model
Break the topic into small operations. Explain what changes after each operation, what must remain true, and how the result is produced.

## 3. Practical Workflow
1. Restate the problem and write a small example by hand.
2. Decide the data representation and the operations required.
3. Write the simplest correct Java implementation.
4. Dry-run a normal case, a boundary case, and an edge case.
5. Test the implementation and compare actual output with expected output.

## 4. Problem-Solving Questions
- What is the invariant or key observation that makes the approach correct?
- Which input causes the smallest or largest amount of work?
- What happens for empty input, one element, duplicates, negative values, or overflow where applicable?
- Can an operation be removed or performed more efficiently without harming correctness?

## 5. Complexity & Correctness
- Count the dominant operations in terms of input size; express the result with Big O notation.
- Separate input storage from auxiliary space. Include recursion stack, temporary arrays, queues, maps, or DP tables when used.
- State whether the analysis is best, average, or worst case when those cases differ.
- Justify correctness using the invariant, induction, or a clear step-by-step argument appropriate to the topic.

## 6. Daily Knowledge Check
- [ ] Explain the concept without looking at notes.
- [ ] Implement one representative Java problem from memory.
- [ ] Dry-run at least two inputs and show every important state change.
- [ ] Test a boundary case and one tricky edge case.
- [ ] State time and auxiliary-space complexity with a reason.
- [ ] Write down one mistake and how to avoid it.

## 7. One-Line Takeaway
Do not memorize only the code: understand the model, prove why it works, test its boundaries, and explain its complexity.
