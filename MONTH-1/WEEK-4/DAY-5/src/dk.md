# Exceptions, static, final & Utilities — Daily Knowledge

> MONTH-1 · WEEK-4 · DAY-5 | Daily learning journal

## 1. Core Knowledge
- Checked exceptions must be caught/declared; unchecked exceptions extend RuntimeException.
- `try/catch/finally`; try-with-resources closes AutoCloseable resources.
- `static` belongs to class; `final` prevents reassignment/overriding/inheritance depending on context.
- Do not swallow exceptions; catch the most specific type and preserve useful context.

## 2. Why It Matters
This concept strengthens your ability to design, read, debug, and explain Java programs. Focus on the reasoning behind each rule rather than memorizing syntax.

## 3. Practical Application
Create a small Java example. Identify inputs, expected output, state changes, and assumptions. Trace a normal case and a boundary case manually, then compare the trace with the program output.

## 4. Questions to Think About

## 5. Complexity & Quality
