# 2D Arrays & Matrix Operations — Concept Notes

> **Roadmap:** Month 1 · Week 3 · Day 6

## Core Idea
Arrays are zero-indexed and fixed-size. Track valid indices; matrix row lengths may differ; one-pass aggregates often avoid repeated traversal.

## Important Concepts
- Understand the definition, purpose, and suitable use-cases of this topic.
- Identify input constraints and the invariant/state that must remain true.
- Compare a straightforward solution with an optimized one and explain correctness.
- Use Java methods, meaningful names, safe types, and appropriate standard-library APIs.

## Implementation & Dry Run
1. Predict output for a small example before coding.
2. Trace variable/reference/state changes step by step.
3. Test empty/minimum input, one element, duplicates, boundaries, and maximum constraints.
4. Re-implement from a blank file without copying.

## Complexity
- **Time:** Count iterations, recursive calls, sorting, and data-structure operations.
- **Auxiliary space:** Count extra arrays, collections, recursion stack, and temporary storage.
- State best/average/worst case when input arrangement changes the work; justify each bound.

## Common Mistakes
- Off-by-one indices, incorrect termination/base cases, stale state, null handling, and integer overflow.
- Using an algorithm without checking its preconditions.
- Ignoring nested work or extra memory while reporting complexity.
