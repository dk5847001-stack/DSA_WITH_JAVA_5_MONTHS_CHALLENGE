# Tree Terminology & Binary Tree Implementation — Daily Knowledge

> MONTH-3 · WEEK-1 · DAY-1 | Daily learning journal

## 1. Core Knowledge
- Binary tree node has at most two children; root has no parent; leaf has no children.
- Height convention must be explicit (edges vs nodes); empty tree height often -1 or 0 depending convention.
- A tree with n nodes has n-1 edges; connected and acyclic.
- Recursive node structure: value, left, right.

## 2. Why It Matters
This concept strengthens your ability to design, read, debug, and explain Java programs. Focus on the reasoning behind each rule rather than memorizing syntax.

## 3. Practical Application
Create a small Java example. Identify inputs, expected output, state changes, and assumptions. Trace a normal case and a boundary case manually, then compare the trace with the program output.
