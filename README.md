## 🎯 Roadmap Objective

This roadmap is designed for a learner who wants to build **Java and
Data Structures & Algorithms from absolute zero to advanced level**.

The plan does not focus only on finishing topics. The main goal is to
develop the ability to:

- Understand a problem before coding.
- Convert logic into Java code.
- Analyze Time and Space Complexity.
- Identify DSA patterns.
- Start with brute force and progressively optimize.
- Solve problems without copying solutions.
- Debug independently.
- Revisit failed problems using spaced repetition.
- Handle interview-style medium and selected hard problems.

### Core Learning Cycle

``` text
Concept
 ↓
Java Implementation

 ↓

 ↓
Complexity Analysis
 ↓

 ↓

 ↓
Re-solve Without Help
```

# ⏱️ Daily 3-Hour Study System

Every study day follows approximately this structure:

 Session Time Work
 ----------- ------------- -------------------------------------
 Session 1 60 min Concept + examples + implementation
 Session 2 90 min Problem solving
 Session 3 30 min Revision + notes + complexity
 Total **3 hours** **Focused learning**

### Problem-Solving Rule

For every new problem:

1. Read the problem carefully.
2. Write down examples.
3. Think of brute force.
4. Estimate complexity.
5. Try an optimized approach.
6. Code in Java.
7. Test edge cases.
8. If stuck for 15--20 minutes, take a hint.
9. Re-code without looking at the solution.
10. Re-solve the problem after 2--7 days.

> **Rule:** Watching a solution is not counted as solving a problem. A
> problem is counted only after you can implement the solution yourself.

# 💻 Java DSA Coding Standards

During the roadmap, follow these rules:

- Use meaningful variable names.
- Avoid unnecessary global variables.
- Write reusable methods.
- Keep methods focused.
- Analyze complexity after every problem.
- Test empty input where applicable.
- Test one-element input.
- Test duplicate values.
- Test negative values when applicable.
- Test maximum/minimum boundaries.
- Avoid copying code without understanding it.
