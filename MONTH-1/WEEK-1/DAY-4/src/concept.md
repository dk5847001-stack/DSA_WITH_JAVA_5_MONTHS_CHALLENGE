> **Roadmap:** Month 1 · Week 1 · Day 4

## 1. Core Concepts

- `Scanner` methods: `nextInt()`, `nextDouble()`, `next()`, `nextLine()`; `next()` token aur `nextLine()` poori line read karta hai.
- `nextInt()` ke baad `nextLine()` call karne par pending newline consume karne ke liye extra `nextLine()` lag sakta hai.
- Input validation aur empty/space-containing strings ke test cases likho.

## 2. Remember These Rules

- **Core idea:** Input/Output with Scanner ko definition, use-case aur implementation ke saath samjho; sirf syntax yaad mat karo.
- **Problem-solving flow:** input/constraints identify karo → small example dry-run → straightforward approach → edge cases → correctness → complexity.
- **Java practice:** clean methods, meaningful names, correct data types, and small test cases use karo.
- **Revision rule:** bina notes dekhe concept explain karo, ek implementation likho, aur ek naya test case solve karo.

## 3. Complexity & Analysis

- Har operation ka cost alag identify karo: traversal, lookup, insertion, sorting, recursion/stack, and auxiliary data structures.
- **Time complexity** input size badhne par work ka growth batati hai; **auxiliary space** algorithm ki extra memory batati hai.
- Best, average, worst case tabhi likho jab input arrangement/behavior se cost change hoti ho. Expected/average hash performance ko guaranteed worst-case mat samjho.
- Complexity ko sirf label mat karo — loop counts, recursive calls, ya data-structure operations se justify karo.

## 4. Common Mistakes to Avoid

- Boundary values, empty input, single element, duplicates, negative values, and maximum constraints ko ignore mat karo.
- Index, loop condition, integer overflow, null references, and state updates ko dry-run karo.
- Code copy karne ke bajay pehle approach explain karo, phir implementation likho.
