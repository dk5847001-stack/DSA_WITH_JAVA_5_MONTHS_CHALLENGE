# Variables & Data Types — Important Notes

> Month 1 · Week 1 · Day 2 | Quick revision sheet

## Must Remember
- Primitive types: byte, short, int, long, float, double, char, boolean; reference types store object references.
- Choose type by range/precision; use `long` for larger integer values and `double` for decimal calculations.
- Local variables need initialization before use; fields receive defaults.
- Widening is generally automatic; narrowing needs an explicit cast and may lose data.

## Quick Complexity / Rules
- Count each loop iteration and nested loop separately.
- Time complexity describes growth with input size; auxiliary space counts extra memory.
- Test empty/minimum, typical, boundary, and invalid inputs.

## Common Traps
- Off-by-one conditions, integer overflow, wrong operator precedence, and unhandled edge cases.
- Do not memorize code blindly: explain why each condition and update is required.
