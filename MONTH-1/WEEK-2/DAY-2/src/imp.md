# while, do-while & Loop Control — Important Notes

> Month 1 · Week 2 · Day 2 | Quick revision sheet

## Must Remember
- `while` checks condition before the body; `do-while` executes at least once.
- Update loop state on every path to avoid infinite loops.
- `break` exits the nearest loop; `continue` skips to the next iteration.
- Use while when termination depends on changing state, such as repeated digit extraction.

## Quick Complexity / Rules
- Count each loop iteration and nested loop separately.
- Time complexity describes growth with input size; auxiliary space counts extra memory.
- Test empty/minimum, typical, boundary, and invalid inputs.

## Common Traps
- Off-by-one conditions, integer overflow, wrong operator precedence, and unhandled edge cases.
- Do not memorize code blindly: explain why each condition and update is required.
