# Final Revision: Graph Algorithms — Concept Notes

> **Roadmap:** Month 5 · Week 4 · Day 5

## Core Idea
Rehearse graph representations, BFS/DFS, cycle detection, topological sort, DSU, shortest paths, and MST. Match each algorithm to its edge constraints.

## Revision Strategy
- Recall the definition, invariant, implementation template, and typical use-case without opening old solutions.
- For each pattern, solve one easy warm-up and one medium-level problem under a time limit.
- Explain brute force, optimized approach, correctness intuition, edge cases, and complexity.
- Maintain a mistake log: what failed, why it failed, the correct pattern, and how to recognize it next time.

## Final Quality Checklist
- [ ] Implement the main data structure/algorithm from memory.
- [ ] Test empty, minimal, duplicate, boundary, and adversarial inputs.
- [ ] Explain time and auxiliary-space complexity.
- [ ] Compare at least one alternative approach.
- [ ] Re-solve a previously failed problem independently.

## Complexity Reminder
Count dominant operations, recursive calls, sorting, heap/collection operations, and extra storage. Separate input space from auxiliary space and state algorithm preconditions explicitly.

## Common Mistakes
- Memorizing code without understanding its invariant.
- Skipping proof intuition, boundary tests, or overflow checks.
- Confusing similar algorithms that have different preconditions or goals.
